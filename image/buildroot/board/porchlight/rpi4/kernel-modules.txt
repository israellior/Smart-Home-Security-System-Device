# The kernel modules the doorbell loads, recorded on the Pi on 2026-10-14
# (release-9) after a clip, a live call and `rauc mount` of a bundle had all
# run in one boot. linux.config is cut down to these, and post-build.sh
# refuses an image that is missing any of them.
#
# A boot's lsmod alone is not enough: dm_bufio, dm_mod, dm_verity and squashfs
# load only while RAUC opens a bundle, so a kernel cut to a normal boot's list
# would run perfectly and never install another update.
#
# Left out on purpose: bluetooth, btbcm, hci_uart, ecc, ecdh_generic and
# libaes - the Wi-Fi chip has Bluetooth and the kernel loaded it, but nothing
# here uses it - and snd_compress, which the old snd_soc_core needed only
# because some other codec driver in bcm2711_defconfig selected compressed
# offload; the cut kernel's snd_soc_core does not depend on it. Both were
# found by the check in post-build.sh, on the first build of the cut kernel.
#
# To add one: load it on the Pi, add its name here (lsmod's spelling), and
# turn it on in linux.config.
